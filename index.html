OrbisRCP update site

This address is a p2 repository: the plugins of OrbisRCP for DBeaver.

  • Groovy editor: a Groovy console with completion, @Grab, access to the DBeaver connections, Vega-Lite charts.
  • H2GIS snapshot: drivers following the development version of H2GIS.
  • PostGIS files import and export: import and export GeoJSON, FlatGeobuf, Shapefile... files in the PostgreSQL/PostGIS connections, with the file drivers of H2GIS (requires H2GIS snapshot).

Install

In DBeaver: Help > Install New Software..., Add..., and give this location:

https://orbisgis.github.io/orbisrcp/

Updates: Help > Check for Updates.
